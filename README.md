# UX Design in the Open Home Foundation

This repository is the central place for UX design within the Open Home Foundation.  
It is fully open and welcomes contributions from designers, researchers, writers, and accessibility experts.

## Purpose

- Make UX work transparent
- Enable community designers to contribute
- Align design across all Open Home Foundation projects
- Document decisions openly

## How design work is organized

- The [**Project Board**](https://github.com/orgs/OpenHomeFoundation/projects/7) contains all active and planned design tasks.
- [**Discussions**](https://github.com/OpenHomeFoundation/ux-design/discussions) are used for proposals, feedback, and research.
- Major decisions are summarized and linked to relevant board items.
- Implemented designs are linked back to product repositories.

Typical flow:

Idea → Discussion → Proposal → Review → Decision → Implementation

## How to get involved

1. Check the Project Board for open design tasks.
2. Join an existing discussion or start a new proposal.
3. Share your work early and request feedback.
4. Link your discussion to the related board item.

Contributions can include:

- UX research
- Wireframes and flows
- Visual design
- Accessibility reviews
- Microcopy improvements
- Design system contributions
